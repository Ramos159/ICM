Phase A: The Overlap Problem

If we just move the raw code into an empty function, it gets stuck in one place. If we call it multiple times, the faces just stack directly on top of each other!

function happyFace() {
// 1. Hardcoded numbers mean it can never move.
ellipse(125, 200, 100);
arc(110, 200, 25, 25, 180, 0);
// ... other shapes ...
}

Phase B: Parameters & Relative Math

We add xPos and yPos parameters to give the head an anchor. Then we use Relative Math (+ or -) to glue the eyes and mouth to the moving head.

// 1. Define the function with parameters (OUTSIDE draw)
function happyFace(xPos, yPos) {
strokeWeight(1);
stroke(0);
fill(169, 222, 183);

// 2. Set the Base Anchor
ellipse(xPos, yPos, 100);

// 3. Use Relative Math (+ or -) for the facial details
arc(xPos - 15, yPos, 25, 25, 180, 0);
arc(xPos + 35, yPos, 15, 25, 180, 0);
arc(xPos + 11, yPos + 26, 40, 10, 0, 180);
}
